Linear Processing
(Pale Blue) 		Below Threshold
(7.1) G_out = G_in, if G_in < T
Linear Pass Characteristics:
• No dynamic processing applied
• Unity gain (0dB) or fixed gain offset
• Preserves original signal dynamics
• Threshold sets processing boundary
No processing below threshold - linear pass-through. Signal dynamics remain unchanged in this region. Signal passes
unmodified
below threshold
Threshold Setting
(7.1a) T = L_avg + margin (dB)
Threshold Guidelines:
• Compression: Set above average level
• Expansion/Gate: Set below useful signal
• Limiting: Set at maximum desired level
• Consider program material characteristics
Threshold level determines when dynamic processing engages. Critical parameter affecting naturalness and effectiveness. Typical thresholds:
Comp: -20dB
Gate: -40dB
Limit: -6dB
Compression
(Pale Green) 		Compressor Transfer
(7.2) G_out = T + (G_in - T)/R, if G_in ≥ T
Compression Ratios:
• 1:1: No compression (linear)
• 2:1 to 4:1: Gentle compression
• 4:1 to 10:1: Medium compression
• 10:1 to ∞:1: Heavy compression/limiting
Reduces gain above threshold by compression ratio. Decreases dynamic range and increases perceived loudness. 4:1 ratio:
4dB in →
1dB out
(above threshold)
Gain Reduction
(7.2a) GR = (G_in - T) × (1 - 1/R)
Gain Reduction Analysis:
• Shows amount of level reduction applied
• Always negative (reduction) above threshold
• Increases with input level and ratio
• Key metric for compressor operation
Amount of gain reduction applied above threshold. Indicates compressor activity and processing depth. 10dB over + 4:1
= 7.5dB reduction
Output: 2.5dB over

Makeup Gain Purpose:

Expansion & Gating
(Pale Pink) 		Downward Expansion
(7.3) G_out = T + (G_in - T) × R, if G_in < T
Expansion Ratios:
• 1:1: No expansion (linear)
• 1:2 to 1:4: Gentle expansion
• 1:4 to 1:10: Strong expansion
• 1:∞ (Gate): Complete cutoff
Reduces level below threshold by expansion ratio. Increases dynamic range and reduces noise floor. 1:2 expansion:
1dB in →
2dB out
(below threshold)
Noise Gate
(7.3a) G_out = T - ∞, if G_in < T (Gate closed)
Gate Applications:
• Noise reduction: Remove hiss, hum
• Isolation: Eliminate bleed between mics
• Rhythm enhancement: Tighten drum sounds
• Creative effects: Chopping, stuttering
Complete signal cutoff below threshold. Extreme form of expansion for noise elimination and creative effects. Gate: ON/OFF
No gradual
transition
Hysteresis
(7.3b) T_open ≠ T_close (T_open > T_close)
Hysteresis Benefits:
• Prevents gate chattering
• Smoother operation near threshold
• Typical difference: 3-6dB
• Essential for musical applications
Different thresholds for opening and closing gate. Prevents rapid switching and chattering effects. Open: -30dB
Close: -35dB

Limiting & Peak Control
(Pale Teal) 		Hard Limiting
(7.4) G_out = T, if G_in ≥ T
Limiting Characteristics:
• Infinite ratio: ∞:1 compression
• Absolute ceiling: No signal above threshold
• Distortion risk: Fast attack required
• Protection: Prevents overload/clipping
Hard ceiling preventing signal from exceeding threshold. Ultimate protection against overload and distortion. Broadcast limiter:
Never exceed
0dBFS
Soft Limiting
(7.4a) G_out = T + (G_in - T)/(R_high), R_high >> 10:1
Soft Limiting Advantages:
• Gentler transition: Less abrupt than hard limiting
• Reduced distortion: Smoother knee response
• Musical limiting: More natural sound
• High ratios: 20:1 to 100:1
High-ratio compression approaching limiting behavior. Provides gentler approach to peak control with reduced artifacts. 20:1 ratio:
Gentle approach
to limiting
Look-ahead Limiting
(7.4b) Delay = t_lookahead ≥ t_attack
Look-ahead Benefits:
• Zero overshoot: Perfect peak control
• Transparent limiting: Minimal artifacts
• Latency cost: Processing delay introduced
• Typical delay: 1-10ms
Delay line allows limiter to "see" incoming peaks before they occur. Enables perfect peak control without overshoot. 5ms lookahead

transient control
Time Constants
(Pale Orange) 		Attack Time
(7.5a) Response: 1 - e^(-t/τ_attack)
Attack Time Guidelines:
• Fast (0.1-1ms): Transient control, limiting
• Medium (1-10ms): Punch preservation
• Slow (10-100ms): Natural compression
• Affects transient response and punch
Time for processor to respond to level increases. Controls how quickly gain reduction is applied to incoming signals. Drums: 1-5ms
Vocals: 2-10ms
Bus: 10-30ms
Release Time
(7.5b) Response: e^(-t/τ_release)
Release Time Guidelines:
• Fast (10-100ms): Pumping risk, tight control
• Medium (100ms-1s): Musical, natural
• Slow (1-10s): Smooth, program dependent
• Affects naturalness and breathing
Time for processor to recover from gain reduction. Controls how quickly the processor returns to unity gain. Auto-release:

program material

Multiband Advantages:

• Frequency isolation: No cross-band pumping

Parallel Compression
(7.8) Output = Dry_Signal + Compressed_Signal
Parallel Compression Benefits:
• Retain transients: Dry signal preserves punch
• Add density: Compressed signal adds body
• Blend control: Mix ratio determines effect
• NY compression: Also called "New York" style
Mixing compressed and uncompressed signals in parallel. Combines density of compression with transient preservation of dry signal. Drums: 70% dry

Measurement & Analysis
(Pale Red) 		Dynamic Range
(7.9) DR = L_peak - L_RMS (dB)
Dynamic Range Considerations:
• Natural music: 20-40dB dynamic range
• Compressed music: 6-12dB dynamic range
• Broadcast: 8-15dB dynamic range
• Measurement window: Affects results significantly
Difference between peak and average levels. Indicates amount of dynamics in signal and compression applied. High DR: natural
Low DR: compressed
or limited

Dynamic Processing Guidelines & Applications

Common Applications by Processor Type:

  • Compressor: Vocal leveling, drum punch control, mix bus glue, loudness enhancement
  • Limiter: Peak protection, broadcast compliance, master bus safety, creative effects
  • Expander: Noise reduction, dynamic enhancement, transient shaping, gate alternative
  • Gate: Noise elimination, track isolation, rhythmic effects, cleanup

Typical Settings: Vocals: 3:1, 5ms attack, 100ms release | Drums: 4:1, 1ms attack, 50ms release | Bus: 2:1, 10ms attack, auto release

Mastering Dynamic Processing Techniques

  1. Understand Transfer Functions: Master how ratio and threshold interact to shape dynamics
  2. Time Constant Selection: Learn appropriate attack/release times for different source material
  3. Detection Methods: Understand peak vs RMS detection and their musical applications
  4. Advanced Techniques: Explore sidechain, multiband, and parallel processing methods
  5. Measurement Skills: Use meters and analysis tools to understand processor behavior
  6. Musical Application: Develop ear training to recognize when and how much processing is appropriate
  7. Creative Processing: Experiment with extreme settings and unconventional applications
