Chapter 3 – Sound Systems and System Integration

Comprehensive reference for system combinations, frequency relationships, and sound system design principles used in audio engineering and acoustical system analysis.

Section Concept Formula/Rule Explanation/Use Case Notes
System Combinations
(Pale Blue) 		Cascaded Systems
(3.1) H_total(f) = H₁(f) × H₂(f) × ... × Hₙ(f)
Cascaded System Properties:
• Systems connected in series (output → input)
• Total gain = product of individual gains
• In dB: L_total = L₁ + L₂ + ... + Lₙ
• Order matters for nonlinear systems
Overall transfer function of cascaded (series-connected) systems. Used for amplifier chains, filter cascades, and signal processing chains. Amp + EQ + Speaker:
H_total = H_amp × H_eq × H_spk
Parallel Systems
(3.2) H_total(f) = (Σ Hᵢ(f)) / n
Context-Dependent:
• Measurement averaging: (Σ Hᵢ)/n
• Parallel speakers: Complex vector addition
• Power combination: P_total = Σ Pᵢ
Parallel System Types:
• Measurement averaging: Multiple measurements of same system
• Loudspeaker arrays: Coherent or incoherent combination
• Parallel amplifiers: Load sharing configuration
• Multi-way systems: Frequency-divided parallel paths
Response of parallel systems depends on application context. Can be arithmetic averaging, power addition, or complex vector combination. Multi-way speaker:
Woofer || Tweeter
(frequency divided)
Frequency Relationships
(Pale Green) 		Octave Frequency
(3.3) f_octave = f₀ × 2ⁿ
Octave Properties:
• n > 0: frequencies above f₀
• n < 0: frequencies below f₀
• Each octave doubles/halves frequency
• Common in audio: 31Hz, 63Hz, 125Hz, 250Hz...
Logarithmic frequency relationship where each octave represents a doubling of frequency. Fundamental to audio analysis and filter design. 1kHz → 2kHz
(+1 octave)
1kHz → 500Hz
(-1 octave)
Bandwidth Definition
(3.4) Δf = f₂ - f₁
Bandwidth Types:
• -3dB bandwidth: Between -3dB points
• -10dB bandwidth: Wider measurement
• Fractional octave: 1/3, 1/6, 1/12 octave bands
• Noise bandwidth: Equivalent rectangular bandwidth
Simple bandwidth calculation between two cutoff frequencies. Essential for filter analysis and system specifications. 800Hz to 1.2kHz
= 400Hz bandwidth
System Characteristics
(Pale Pink) 		Quality Factor
(3.5) Q = f₀ / Δf
Q Factor Applications:
• High Q (>10): Sharp, selective filters
• Medium Q (1-10): Audio equalizers
• Low Q (<1): Broad, gentle filters
• Resonant systems: Speaker enclosures, rooms
Measure of resonance sharpness and filter selectivity. Higher Q indicates narrower bandwidth relative to center frequency. f₀=1kHz, BW=100Hz
Q = 10
(narrow band)
Combined Power Levels
(3.6) L_total = 10 log₁₀(Σ Pᵢ / P_ref)
Power Combination Rules:
• Incoherent sources: Powers add directly
• Coherent sources: Voltages add, then square
• Reference power: Often 1W or 1mW
• Multiple speakers: Usually incoherent
Total sound level from multiple incoherent power sources. Used for calculating combined output from multiple speakers or amplifiers. Two 10W sources:
L = 10log₁₀(20/1)
= 13.01 dB(W)
Advanced Concepts
(Pale Teal) 		Fractional Octave Bands
(3.7) f_upper/f_lower = 2^(1/n)
Standard Fractional Octaves:
• 1/3 octave: f₂/f₁ = 2^(1/3) ≈ 1.26
• 1/6 octave: f₂/f₁ = 2^(1/6) ≈ 1.12
• 1/12 octave: f₂/f₁ = 2^(1/12) ≈ 1.06
• Used in spectrum analyzers and EQ design
Frequency ratio for fractional octave band analysis. Essential for acoustic measurements and graphic equalizer design. 1/3 octave:
1kHz band
891Hz-1122Hz
System Delay
(3.8) τ = d/c = d/343 (m/s at 20°C)
Delay Considerations:
• Speed of sound: ~343 m/s at 20°C
• Temperature dependent: +0.6 m/s per °C
• Time alignment: Critical for multiple speakers
• Phase alignment: Affects frequency response
Acoustic delay between source and receiver. Critical for speaker alignment and sound system timing in large venues. 10m distance:
τ = 29.2 ms
@20°C
Coherence Function
(3.9) γ²(f) = |G_xy(f)|² / [G_xx(f)G_yy(f)]
Coherence Applications:
• γ² = 1: Perfect linear relationship
• γ² = 0: No linear relationship
• System identification: Input-output correlation
• Noise floor: Measurement quality indicator
Measure of linear relationship between two signals. Used to assess measurement quality and system linearity. Good measurement:
γ² > 0.9
across frequency
Practical Design
(Pale Orange) 		Array Gain
(3.10) G_array = 10 log₁₀(N) (incoherent)
Array Configurations:
• Incoherent: G = 10log₁₀(N) dB
• Coherent: G = 20log₁₀(N) dB
• Line arrays: Directional control
• Point source arrays: Coverage extension
Gain from combining multiple identical sources. Depends on coherence between sources and frequency relationships. 4 speakers incoherent:
G = 6.02 dB
4 speakers coherent:
G = 12.04 dB
Coverage Angle
(3.11) θ = 2 × arcsin(λ/2L)
Coverage Design:
• λ: Wavelength at frequency of interest
• L: Length of line array
• Higher frequency: Narrower coverage
• Longer array: Narrower coverage
Coverage angle for line array systems. Determines directional characteristics and audience coverage patterns. 2m array @ 1kHz:
θ ≈ 20°
(narrow beam)

🔧 System Design Guidelines & Quick Reference

Common System Configurations:

  • Cascaded: Amplifier → EQ → Crossover → Speakers (gains multiply)
  • Parallel: Multi-way speakers, speaker arrays, redundant systems
  • Hybrid: Matrix systems, distributed arrays, zoned systems

Typical Values: Q-factors: 0.7-10 | Octave bands: 31Hz-16kHz | Array gains: 3-12dB | Delay: ~3ms/meter

🎯 System Design & Analysis Guidelines

  1. System Architecture: Understand cascaded vs. parallel system behavior and when to use each
  2. Frequency Analysis: Master octave relationships and fractional octave band calculations
  3. Quality Assessment: Use Q-factor and coherence measurements for system evaluation
  4. Array Design: Apply array gain principles for coverage and SPL requirements
  5. Time Alignment: Account for acoustic delays in multi-speaker systems
  6. Measurement Techniques: Use appropriate averaging and analysis methods for different system types
